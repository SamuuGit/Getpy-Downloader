# Getpy-Downloader
Cansei de usar conversores de música genéricos e inseguros, então decidi criar minha própria solução gratuita. Como o Getpy utiliza o yt-dlp como núcleo, ele oferece suporte a mais de 1600+ sites com alta confiabilidade e segurança.
*Uso gratuito:* O programa é 100% gratuito para uso pessoal.
